# 📚 Repositório de Materiais para aulas de Projetos Integradores

Este repositório foi criado com o objetivo de reunir materiais didáticos sobre **Scrum**, voltados para **aulas, estudos e práticas em sala de aula**. Ele serve como material de apoio para estudantes, professores e profissionais que estão aprendendo ou ensinando metodologias ágeis.

---

## Objetivo

- Fornecer conteúdos organizados para aulas de Scrum
- Centralizar guias, exemplos e diagramas explicativos
- Facilitar o aprendizado do ciclo de cerimônias, papéis e práticas ágeis

---

## 📂 Estrutura do Repositório

- `README.md` → Apresentação do repositório  
- `Documentos/` → Tutoriais, guias e resumos do Scrum  
- `diagramas/` → Diagramas do ciclo Scrum e fluxos  
- `exemplos/` → Modelos de Sprint, Backlog e exemplos práticos

---

## 📚 Conteúdos que podem ser encontrados

- Explicação detalhada das cerimônias do Scrum
- Tabelas e resumos das responsabilidades dos papéis
- Diagramas ASCII ou gráficos ilustrativos
- Exercícios e exemplos para sala de aula

---

## ⚠️ Uso

Este repositório é destinado **apenas para fins educacionais**. Todo conteúdo tem caráter didático e serve como apoio em aulas ou estudos sobre Scrum. Professora Kadidja Valéria
